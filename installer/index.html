Comment installer sur Mac ?

  1. Télécharge Equiflow-1.0.0-arm64.dmg.
  2. Ouvre le fichier .dmg dans Finder.
  3. Si la fenêtre le propose, glisse Equiflow dans le dossier Applications.
  4. Ouvre Equiflow depuis Applications.

Une application non signée ou non notarisée peut afficher un avertissement de sécurité macOS. N'ignore pas un avertissement si tu n'as pas vérifié l'origine du fichier.
