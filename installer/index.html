EQUIFLOW / INSTALLATION

À votre rythme.
Partout.

Equiflow fonctionne directement dans votre navigateur. Sur certains appareils, vous pouvez aussi l'ajouter à votre écran d'accueil comme une application.

Ouvrir la version web ↗Télécharger les fichiers ZIP ↓

Sur iPhone ou iPad

  1. Ouvrez la version web dans Safari.
  2. Appuyez sur Partager.
  3. Sélectionnez « Sur l'écran d'accueil » puis Ajouter.

Sur Android ou ordinateur

Ouvrez l'application avec Chrome, Edge ou un navigateur compatible et choisissez « Installer » ou « Ajouter à l'écran d'accueil » dans son menu.

Le ZIP contient les sources de l'application web et du site, et non un programme .dmg ou .exe. Les données sont enregistrées localement dans votre navigateur.
